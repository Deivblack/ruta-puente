# Ruta Puente

Landing y formulario previo a la entrevista para profesionales latinos en EE.UU.

- `index.html`: la página (GitHub Pages).
- `logo.svg`, `logo-mark.svg`, `logo-icon.svg`: el logo.
- `apps-script.gs`: script de Google que guarda cada respuesta en una hoja y calcula la prioridad.

Para conectar el formulario, pega la URL de la aplicación web de Apps Script en `SCRIPT_URL` dentro de `index.html`.
